## ১. সারসংক্ষেপ (Executive Summary)

Sikhun.com একটি **AI-চালিত বাংলাদেশি শিক্ষা প্ল্যাটফর্ম**। এটি একইসাথে ডিজিটাল বইয়ের লাইব্রেরি, মেন্টর-পরিচালিত কোর্স, AI স্টাডি অ্যাসিস্ট্যান্ট (বইভিত্তিক চ্যাট, পরীক্ষা, ফ্ল্যাশকার্ড, রচনা মূল্যায়ন, স্টাডি প্ল্যান), ওয়ালেট, সাবস্ক্রিপশন এবং একটি পূর্ণাঙ্গ অ্যাডমিন প্যানেল — সব একসাথে দিতে চেষ্টা করছে।

**প্রযুক্তিগত দিক থেকে এটি একটি পরিপক্ব, ভালোভাবে সাজানো কোডবেস।** সার্ভিস লেয়ার, মাল্টি-গার্ড অথেন্টিকেশন, সাইনড URL দিয়ে সুরক্ষিত বই রিডার, রেডিস কিউ, পুশ নোটিফিকেশন, SEO, অ্যানালিটিক্স — সবই আছে। লোকাল পরিবেশে সফলভাবে চালু হয়েছে।

**ব্যবসায়িক দিক থেকে সবচেয়ে বড় তিনটি সুযোগ:**

1. **"নিজের বই আপলোড করে AI-এর সাথে পড়া"** — বাংলাদেশে এই ফিচারটি কার্যত নেই। এটি Sikhun-এর প্রধান ডিফারেনশিয়েটর।
2. **অধ্যায়ভিত্তিক (chapter-wise) বই বিক্রি** — শিক্ষার্থীরা পুরো বই কিনতে চায় না, একটা অধ্যায় কিনতে চায়। ৳৯–২৯ দামে এটি বিশাল ভলিউম আনতে পারে।
3. **B2B স্কুল/কোচিং লাইসেন্সিং** — ব্যক্তিগত গ্রাহকের চেয়ে প্রতিষ্ঠান বিক্রি অনেক সহজ ও স্থিতিশীল।

**সবচেয়ে বড় তিনটি ঝুঁকি:**

1. **পাসওয়ার্ড রিসেট ফ্লো নেই** — ব্যবহারকারী পাসওয়ার্ড ভুলে গেলে চিরতরে হারিয়ে যাবে। এটি লঞ্চ ব্লকার।
2. **bKash/Nagad সরাসরি নেই** — শুধু ZiniPay। বাংলাদেশে ডিজিটাল পেমেন্টের ৯০%+ bKash/Nagad-এ হয়।
3. **সব টেস্ট ফেইল করছে (৩৫/৩৫)** — একটি MySQL-নির্ভর মাইগ্রেশন SQLite টেস্ট ডেটাবেস ভেঙে দিচ্ছে। অর্থাৎ বর্তমানে কোনো কোড পরিবর্তন নিরাপদে যাচাই করা সম্ভব নয়।

**সুপারিশ:** প্রথম ৩০ দিনে শুধু ভিত্তি ঠিক করুন (পেমেন্ট, পাসওয়ার্ড রিসেট, ফোন/OTP, টেস্ট, কনটেন্ট)। ৩১–৬০ দিনে গ্রোথ ইঞ্জিন (SEO + রেফারেল + সোশ্যাল)। ৬১–৯০ দিনে রিটেনশন ও B2B। এই ক্রমে গেলে ৬ মাসে ৫০০–১,০০০ পেইড ইউজার একটি বাস্তবসম্মত লক্ষ্য।

## ৩. প্রযুক্তিগত মূল্যায়ন

### ৩.১ যা সত্যিই ভালো (এগুলো ধরে রাখুন)

- **সার্ভিস লেয়ার সঠিকভাবে ব্যবহৃত** — `PurchaseService` এক জায়গা থেকে বই, কোর্স, সাবস্ক্রিপশন, ওয়ালেট — সব কেনাকাটা সামলায়। `DB::transaction` ব্যবহার হয়েছে। এটি অনেক বড় প্রজেক্টের চেয়ে পরিষ্কার।
- **বইয়ের কনটেন্ট সুরক্ষা** — PDF পেজ সরাসরি সার্ভ হয় না; signed + throttled URL দিয়ে ইমেজ হিসেবে সার্ভ হয়। পাইরেসি প্রতিরোধে চিন্তাশীল ডিজাইন।
- **মাল্টি-গার্ড অথেন্টিকেশন** — স্টুডেন্ট, অ্যাডমিন, API সম্পূর্ণ আলাদা। নিরাপত্তার দিক থেকে সঠিক।
- **৮টি AI প্রোভাইডার + ফলব্যাক** — এক প্রোভাইডার ডাউন হলে অন্যটি ব্যবহার করা যায়। খরচ নিয়ন্ত্রণের সুযোগ আছে।
- **বাংলা-ইংরেজি দ্বিভাষিক সিস্টেম** — `lang/bn.json` (৪০.৭ KB) ও `lang/en.json` (২৫.৯ KB), Inertia-তে শেয়ার করা।
- **অ্যাডমিন প্যানেলের গভীরতা** — চাঙ্কড আপলোড, PDF পার্সিং রিট্রাই, AI লগ অডিট, ওয়ালেট ম্যানুয়াল অ্যাডজাস্ট — বাস্তব অপারেশনের জন্য প্রস্তুত।
- **অ্যানালিটিক্স ও SEO ভিত্তি** — GA4, Meta Pixel, GTM, JSON-LD, sitemap কমান্ড — লঞ্চের জন্য প্রস্তুত।
- **৭টি ফিচার টেস্ট ফাইল** — কম, কিন্তু শূন্য নয়। ভিত্তি আছে।

## পরিশিষ্ট: লোকাল সেটআপ (Windows)

```powershell
git clone https://github.com/mokaddes/Sikhun.git
cd Sikhun

# Windows-এ Horizon-এর ext-pcntl/ext-posix নেই
composer install --ignore-platform-req=ext-pcntl --ignore-platform-req=ext-posix
npm install

# .env তৈরি করে MySQL + Redis সেট করুন
php artisan key:generate
php artisan migrate:fresh --seed
php artisan storage:link
npm run build
php artisan serve
```

**লগইন:**
| ধরন | ইমেইল | পাসওয়ার্ড |
|---|---|---|
| স্টুডেন্ট | `student1@sikhun.com` | `student123` |
| অ্যাডমিন | `admin@sikhun.com` | `admin123` |

**যেসব এক্সটেনশন/সার্ভিস দরকার:** MySQL 8, Redis, (ঐচ্ছিক) Meilisearch, Node 20+।
**AI ফিচার পরীক্ষার জন্য:** `.env`-এ অন্তত একটি প্রোভাইডার কী (যেমন `OPENAI_API_KEY`) দিতে হবে।
