## M1.5 — ফন্ট, ডিজাইন ও নতুন পজিশনিং (সপ্তাহ ১–২, সমান্তরাল)

### ২.১ ফন্ট সমস্যা — মূল কারণ ও সমাধান ✅ সম্পন্ন
বর্তমানে `DM Sans` আগে, `Hind Siliguri` পরে। বাংলা অক্ষর Hind Siliguri-তে গেলেও **সংখ্যা DM Sans-এ** যাচ্ছে — তাই ০১২৩৪৫ দেখতে ভুল লাগছে।

**যা করা হয়েছে:**
```css
/* resources/css/app.css */
@import url('...&family=Anek+Bangla:wght@400;500;600;700...');
body { font-family: 'DM Sans', 'Anek Bangla', 'Noto Sans Bengali', sans-serif; }
h1, h2, h3, h4, .font-heading { font-family: 'DM Sans', 'Anek Bangla', 'Noto Sans Bengali', sans-serif; }
```
- **Anek Bangla** যোগ করা হয়েছে (fallback: `Noto Sans Bengali`, `sans-serif`)
- `resources/js/utils/format.js` — `toBnDigits()`, `formatNumber()`, `formatMoney()`
- `useI18n()` এখন `n()`, `money()`, `digits()` রিটার্ন করে, তাই locale বদলালে সংখ্যাও বদলায়
- বাংলা সংখ্যা প্রয়োগ হয়েছে: হোমপেজ, প্ল্যান, ড্যাশবোর্ড, ওয়ালেট, লাইব্রেরি, কোর্স, রেফারেল, স্টুডেন্ট লেআউট
- অ্যাডমিন প্যানেলে আপাতত ল্যাটিন সংখ্যা রাখা হয়েছে (ইনপুট/টেবিলে ভুল এড়াতে)

**উদ্দেশ্য:** পেমেন্ট গেটওয়ে বদলানো নয় — ZiniPay-ই থাকবে। শুধু **হিসাব ও ইনভয়েস** পাকা করা, যাতে আয় ট্র্যাক করা যায় এবং শিক্ষার্থী/অভিভাবক ইনভয়েস পায়।

### ২.১ ZiniPay যাচাই (নতুন কোড নয়, শুধু যাচাই)
- হোস্টেড চেকআউটে bKash / Nagad / Rocket / কার্ড সব চ্যানেল আছে — লাইভ কী দিয়ে একটি টেস্ট পেমেন্ট করে নিশ্চিত করা
- `initiate()`-এর redirect সব অর্ডার টাইপে কাজ করছে কিনা যাচাই (M1-এ ঠিক করা হয়েছে)
- Webhook idempotency + `gateway_invoice_id` ইনডেক্স (M1-এ যোগ হয়েছে)
- ব্যর্থ পেমেন্টে অর্ডার `pending` থেকে যায় — ২৪ ঘণ্টা পর `failed` করার শিডিউল

### ২.২ ইনভয়েস
**নতুন টেবিল**
```
invoices: id, student_id, order_id, invoice_number (unique), type(one_time|recurring),
          period_start, period_end, issued_at, due_at, subtotal, discount, vat, total,
          currency(BDT), status(draft|sent|paid|void|overdue), pdf_path, notes, meta
invoice_items: invoice_id, description, qty, unit_price, amount
```

**ফিচার**
- অর্ডার সম্পন্ন হলে অটো ইনভয়েস (PDF, DomPDF আগেই আছে)
- স্টুডেন্ট: `/invoices` — ডাউনলোড, প্রিন্ট
- অ্যাডমিন: ইনভয়েস এডিট (পরিমাণ, তারিখ, নোট), void, re-issue, manual invoice
- **রিকারিং:** সাবস্ক্রিপশনের জন্য প্রতি মাসে অটো ইনভয়েস (`subscriptions:generate-invoices`)
- **রিমাইন্ডার:** `due_at`-এর **৫ দিন ও ১ দিন আগে** ইমেইল + ইন-অ্যাপ
- VAT লাইন কনফিগারেবল (`site_settings.vat_percent`), ডিফল্ট ০%

## M4 — AI কোয়ালিটি, Explain, Book Reference (সপ্তাহ ৫–৭)

### ৪.১ মূল বাগ: শুধু প্রথম পাতা ব্যবহার
**বর্তমান কোড**
```php
// GenerateExamQuestions.php:39
$session->book->chunks()->orderBy('chunk_index')->limit(6)->pluck('content')->implode("\n")
```

**সমস্যা:** ৩০০ পাতার বইয়ের প্রথম ৬ চাঙ্ক (≈প্রথম ২–৩ পাতা) ব্যবহার হয়। বাকি বই সম্পূর্ণ উপেক্ষিত।

**সমাধান**
- `BookChunkRetrievalService` ব্যবহার করুন (এতে access-aware retrieval + spread sampling আছে)
- **অধ্যায় নির্বাচন বাধ্যতামূলক:** বই বেছে নিলে কোন অধ্যায়/পূর্ণ বই — ইউজারকে জিজ্ঞাসা
- **কভারেজ-ভিত্তিক স্যাম্পলিং:** প্রতিটি অধ্যায় থেকে সমান সংখ্যক চাঙ্ক
- **টোকেন বাজেট:** ৬,০০০ অক্ষর নয়, মডেল অনুযায়ী ৮k–৩২k টোকেন
- **যাচাই:** `book.processing_status === 'completed'` এবং `chunks_count > 0`, নাহলে স্পষ্ট এরর
- প্রম্পটে সোর্স লেবেল: `[অধ্যায় ৩, পৃষ্ঠা ৪২]`

### ৬.৩ মিডিয়া: Drive বনাম স্কেলেবল স্টোরেজ (আইটেম ১৪)
**প্রশ্ন: Drive থেকে PDF/ভিডিও চালানো স্কেলেবল?**

**সংক্ষেপে: না।** কারণ:
| সমস্যা | ব্যাখ্যা |
|---|---|
| ব্যান্ডউইথ | Drive হটলিংক রেট-লিমিট করে, বড় ভিডিওতে বাফার |
| Signed URL | নেই — কনটেন্ট সুরক্ষা অসম্ভব |
| ToS | পাবলিক হোস্টিং হিসেবে ব্যবহার নিষিদ্ধ হতে পারে |
| খরচ | Drive storage সস্তা, কিন্তু ডেলিভারি নিয়ন্ত্রণ নেই |
| ভিডিও | HLS/অ্যাডাপ্টিভ স্ট্রিমিং নেই → মোবাইল ডেটা নষ্ট |

**সুপারিশ (স্কেলেবল)**
```
Admin upload → VPS (temporary) → transcode (FFmpeg) → R2/B2 → CDN → signed URL
```
| স্তর | প্রযুক্তি | খরচ (আনুমানিক) |
|---|---|---|
| অবজেক্ট স্টোরেজ | Cloudflare R2 | $0.015/GB/মাস, **egress ফ্রি** |
| CDN | Cloudflare | ফ্রি/প্রো |
| ভিডিও | HLS (FFmpeg) | একবার ট্রান্সকোড |
| PDF | R2 + signed URL | বর্তমান `private` ডিস্কের মতো |

**Drive-কে রাখুন শুধু "ইমপোর্ট সোর্স" হিসেবে:** অ্যাডমিন Drive লিংক দিলে সার্ভার ফাইল নামিয়ে R2-তে রাখবে। ডেলিভারি কখনো Drive থেকে নয়।

## M7 — পারফরম্যান্স, VPS, লঞ্চ (সপ্তাহ ১০–১১)

### ৭.১ VPS (আইটেম ১৩)

### ৭.২ পারফরম্যান্স (আইটেম ১৫)
**ব্যাকএন্ড**
- Redis ক্যাশ: হোমপেজ, লাইব্রেরি ফিল্টার, প্ল্যান
- DB ইনডেক্স: `books(level,subject,is_published)`, `orders(student_id,status)`, `exam_sessions(student_id,status)`
- `Model::preventLazyLoading()` দিয়ে N+1 ধরা
- Queue worker সংখ্যা বাড়ানো, `--timeout` টিউন

**ফ্রন্টএন্ড**
- ApexCharts ডাইনামিক ইমপোর্ট (৬১৩ KB → শুধু অ্যাডমিন)
- ফন্ট সাবসেট + `font-display: swap`
- ইমেজ: WebP/AVIF + `srcset` + lazy load
- Brotli + HTTP/2 + CDN
- রুট-লেভেল কোড স্প্লিট

**AI গতি**
- Groq/Gemini Flash → দ্রুত first token
- প্রম্পট ক্যাশিং (Anthropic) / context caching (Gemini)
- ছোট প্রম্পট, কম টোকেন
- স্ট্রিমিং সব জায়গায়
- প্রি-ওয়ার্ম জনপ্রিয় বইয়ের এমবেডিং
